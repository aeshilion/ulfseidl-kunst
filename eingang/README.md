# Eingang für neue Bilder

Hier legt Ulf Fotos neuer Werke ab. Auf GitHub: **Add file → Upload files**, Bilder hineinziehen, unten **Commit changes**.

Danach in Claude schreiben: „Mach aus den neuen Bildern im Eingang Werke.“
Claude verkleinert sie, legt sie nach `static/werke/`, fragt nach Titel, Jahr und Technik und leert den Eingang wieder.

Was hier liegt, ist noch **nicht** auf der Seite.
